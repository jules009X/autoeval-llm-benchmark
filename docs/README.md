## État des preuves

Les réponses se trouvent dans [l'export du pilote](../results/pilot-v0.1.json). Les références sont dans [le catalogue](../data/cases.json). Les versions des sources, des modèles et du code du moteur sont conservées dans [le dossier data](../data/). Les PDF et modèles se récupèrent séparément ; les notes humaines n'ont pas encore été collectées.
